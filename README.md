## How I work

Best fit: clear tasks or milestones where there is an existing project, repo, plugin, server or Roblox place and something needs to be built, fixed, integrated or tested.

Typical flow:

1. Inspect the current project
2. Reproduce or define the issue
3. Make the smallest reliable change
4. Test it
5. Return the updated work with a short summary

Written/async communication is preferred, with progress updates. Occasional calls are fine when useful.
